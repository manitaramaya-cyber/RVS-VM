ระบบบริหารยานพาหนะ ฝ่ายบริหารงานทั่วไป โรงเรียนรุ่งอรุณวิทยา V.1.2.9
Calendar.html
	ผู้ใช้เข้าโดยไม่ใส่รหัสใด ๆ 
	เจอปฏิทินที่ระบุใครจองรถไปใช้ที่ไหนวันไหนบ้าง
	กดปุ่มจองรถ ระบุรายละเอียดให้ครบ กดส่ง 
	คำขอเด้งไปที่ Admin.html รออนุมัติรถ
	ผู้ใช้ สั่งพิมพ์ใบขออนุญาตใช้รถยนต์ ลงชื่อกำกับ แล้วส่งที่งานยานพาหนะ เก็บเอกสาร
	Admin อนุมัติรถ คำขอเปลี่ยนสถานะ จากรอดำเนินการเป็น อนุมัติแล้ว หรือ จัดรถแล้ว ระบุว่าใช้คันไหน จบ
Admin.html 
	เข้าโดยต่างรหัส ต่างสิทธิ์ 
	เข้ามาเจอปฏิทินเดียวกันกับผู้ใช้ใน Calendar.html
	มีพาแนลขวามือ แจ้งเตือน รีเฟรชตลอดว่า มีคำขอใหม่หรือไม่ ถ้ามี ค่อยอนุมัติ 
	ส่วนใหญ่ เอกสารใบขออนุญาตใช้รถยนต์ จะต้องแจ้งให้ ผู้แทนผู้รับใบอนุญาตทราบ และลงนามก่อน จากนั้น Admin จึงจะยอมอนุมัติ จัดรถให้
	กติกาควรขอล่วงหน้าอย่างน้อย 7 วัน
	Admin คลิกที่วันที่บนปฏิทินวันไหนที่มีคำขอ จะเด้งเข้าพาแนลกลาง เพื่อจัดสรรรถได้ 
	จัดสรรคนขับรถก็ได้ แจ้งเตือนว่าคนขับคนนี้ปฏิบัติหน้าที่ค้างอยู่ในวันและเวลาอื่นที่จัดไปแล้วก็ได้ แก้ไขคนขับก่อนหน้าก็ยังได้ เริ่ด
	หาก Admin ลืม ดันจัดรถคันเดียวกันในวันและเวลาเดียวกันที่อนุมัติไปก่อนหน้า ระบบก็เด้งเตือนว่า จะเอาไงดี แก้ได้หมด เริ่ด
	แท็บ บันทึกคำขอใหม่ ใช้กรณีผู้สั่งการใหญ่โตมาก ทำเองไม่ได้ Admin บันทึกให้ก็ได้ มีค่าเท่ากัน เริ่ด
	แท็บ จัดรถ เปิดมาเจอทุกราย Admin หาได้จนตาเหลือก แล้วก็เลือกอนุมัติเอา เริ่ด
	แท็บ ปฏิทิน เป็นปฏิทินเดียวกัน แต่ใหญ่กว่า เอาไว้ดูสรุปใหญ่ แต่อันเล็กในหน้า Dashboard ดูได้เร็วกว่า เริ่ด
	แท็บ รถในกองรถ จริง ๆ อยากตั้งชื่อว่าลานจอดรถ เวลามองไปคันไหนอยู่ พร้อมใช้ก็รู้ มองไปไม่อยู่ก็รู้ว่าเออ มีคนใช้ สถานะคล้าย ๆ กัน วันที่ตรงกับการใช้รถยนต์นั้น จะขึ้นสถานะว่า กำลังใช้งาน อย่าได้เสือกจัด เริ่ด
แท็บ สรุปประจำวัน ทำงานเพื่อสรุปว่า วันนี้ใครจะใช้รถไปไหน โดยมีแพทเทิร์นรายงานอยู่ในนั้น Admin จะก๊อปไปวางใน Line ก่อนจะใช้รถ 12 ชั่วโมง แต่ตรงนี้ แอบรู้สึกว่า จะลิงค์กับบอทในไลน์ สร้างบอทมาหนึ่งคนชื่อแอร์เมส สังกัดยานพาหนะ (ผู้ส่งสารของเทพกรีก) ลิงค์ข้อมูลกับ Admin.html แล้วตั้งเวลาให้รายงานล่วงหน้า 24/12/6/3/1 ช.ม. ก่อนใช้งานก็ได้ ถ้ารายงานแล้วไม่ต้องรายงานอีก เริ่ด แต่ฟีเจอร์นี้ยังไม่อนุมัติให้ใช้ 
แท็บ Report แอบหงุดหงิดเพราะชื่อเกือบซ้ำ จริง ๆ คือ Log ที่บันทึกการกระทำทุกอย่างจากทุกคนในระบบ Admin คนไหนล็อกอินก็รู้ ใครส่งคำขอใช้รถก็รู้ ลบอะไรไปก็รู้ อนุมัติ ยกเลิก ปฏิเสธอะไรก็รู้ จะบันทึกไว้ในนี้ทั้งหมด เริ่ด

V.2.0.0 เพิ่ม

แท็บ Vehicle Handover / คืนรถ อันที่จริง ต้องมี XX.html อีกอัน ไว้ทำงานโดยฝั่งผู้ขอใช้รถ เมื่อนำรถมาจอดเก็บในโรงรถ ต้องถ่ายรูป
1. รูปภายในห้องโดยสาร ว่าได้เคลียร์ของทำความสะอาด รถยนต์ ให้พร้อมใช้สำหรับคนต่อไป 
2. ต้องระบุว่า เลขไมล์ขณะคืนรถ คือเลขอะไร ระบุว่า น้ำมันคงเหลือ อยู่ในขีดไหน (แบ่งย่อยเป็น 100/75/50/25/0) และคืนกุญแจไว้ที่ใคร (ห้องธุรการ/รปภ.1)
3. จอดรถในช่องจอดตามหมายเลขทะเบียน
4. ข้อมูลทั้งหมด ลิงค์มาที่ แท็บ คืนรถ ใน Admin.html 

แท็บ Compliance & Expiry Alerts / เอกสารสำคัญของรถยนต์ 
1. กำหนดวันหมดอายุของ พรบ. / ประกัน / ทะเบียน / ภาษี แจ้งเตือน Admin ล่วงหน้าได้ ถึง 180 วัน ในหน้า Dashboard Panel ขวามือ และมีจุดสีน้ำตาลบนปฏิทินของ Admin.html สามารถกด ดำเนินการต่ออายุแล้ว เพื่อลิงค์ไปยังหน้าบันทึกข้อมูลใหม่ เมื่อบันทึกครบถ้วน กดอัพเดทข้อมูล ข้อมูลเก่าเก็บลง log โชว์เป็นข้อมูลใหม่ในแท็บ หรือกด รับทราบ ไม่ต้องแจ้งเตือนอีก ก็ได้ ถ้าไม่กด ก็ให้แจ้งเตือนอยู่อย่างนั้น
		2. บันทึกเอกสารล่าสุด (สแกน fille PDF) อัพโหลด เก็บไฟล์ ดูภายหลังโดยไม่ต้องไปค้นหาในซอง 

แท็บ Maintenance History / ประวัติการซ่อมบำรุง
1. กดเลือกรถยนต์คันที่ต้องเข้ารับการซ่อมบำรุง
		2. เลือกวันที่รับการซ่อมบำรุง 
		3. ระบุอาการเสีย หรือ การซ่อมแซม พิมพ์ยาว ๆ ได้ กดเอนเทอร์ เพื่อขึ้นบรรทัดใหม่ได้
4. กดเก็บประวัติการซ่อมบำรุง
5. มีช่องสำหรับเลือกว่า ต้องการ / ไม่ต้องการ ให้แจ้งเตือนเพื่อเข้ารับการซ่อมบำรุง ถ้าต้องการ จะต้องเด้งไปที่หน้า Dashboard ของ Admin.html แจ้งเตือนที่ พาแนลขวา เรื่องแจ้งเตือน มีปุ่มกดว่า ดำเนินการแล้ว / ไม่ต้องแจ้งเตือนอีก การแจ้งเตือนจะหายไป
		6. มีระบบประเมินสภาพรถ ความพร้อมในการใช้งาน ตั้งแต่ 0 – 100 % Admin ประเมินเองได้เลย เกณฑ์คือ 
รับการบำรุงรักษาอยู่ตลอดไม่ขาด ไม่มีสัญญาณความผิดปกติ ไม่มีผู้ใช้คนใดแจ้งความผิดปกติ (100%) 
รับการบำรุงรักษาอยู่ตลอดไม่ขาด มีสัญญาณความผิดปกติหนึ่งรายการ ไม่รุนแรง ใช้ได้ (90%)
		การบำรุงรักษาไม่ต่อเนื่อง มีสัญญาณความผิดปกติ 1 – 3 รายการ ไม่รุนแรง ใช้ได้ (70%)
		การบำรุงรักษาไม่ต่อเนื่อง มีสัญญาณความผิดปกติ 3 - 5 รายการ ไม่รุนแรง ใช้ได้ในพื้นที่ใกล้เคียง (50%)
		ตรวจพบความผิดปกติ อันตราย ไม่ควรใช้งาน (น้อยกว่า 50%)
